Los contenedores son efímeros por naturaleza. En este tema aprenderemos a hacerlos útiles para aplicaciones reales.

## ¿Qué veremos aquí?

- **Volúmenes (Volumes)**: Cómo persistir los datos de nuestra base de datos MySQL para que no desaparezcan al borrar el contenedor.
- **Bind Mounts**: Conexión de nuestro código fuente local con el contenedor para desarrollo en tiempo real.
- **Redes (Networks)**: Creación de redes privadas para que PHP y MySQL hablen entre sí de forma segura.
