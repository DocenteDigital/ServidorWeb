Docker en Windows depende de una integración profunda con Linux a través de WSL 2.

## ¿Qué veremos aquí?

- **Instalación de WSL 2**: Comandos necesarios y verificación del kernel.
- **Docker Desktop**: Descarga, instalación y configuración para usar el motor de WSL 2.
- **Verificación**: Comprobación de que el motor de Docker responde correctamente desde la terminal de Windows.
- **Recursos**: Enlaces a la documentación oficial y solución de problemas comunes de virtualización.
