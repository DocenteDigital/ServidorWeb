Para dominar Docker es vital entender la diferencia entre lo que se construye y lo que se ejecuta.

## ¿Qué veremos aquí?

- **Imágenes (Images)**: Entendiendo las imágenes como plantillas inmutables y en capas.
- **Contenedores (Containers)**: La instancia ejecutable de una imagen.
- **Docker Hub**: Exploración del registro público para encontrar imágenes oficiales de PHP, MySQL, Apache, etc.
- **Tagging**: Cómo gestionar las versiones de nuestras imágenes.
