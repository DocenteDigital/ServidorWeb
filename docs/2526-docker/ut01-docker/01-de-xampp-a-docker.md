Este tema explora el cambio de paradigma en el desarrollo web.

## ¿Qué veremos aquí?

- **Limitaciones de XAMPP**: El problema de "en mi máquina funciona".
- **Definición de Contenedor**: Aislamiento, ligereza y portabilidad.
- **Docker vs. Máquinas Virtuales**: Por qué Docker es mucho más eficiente en el uso de recursos.
- **Beneficios para el Desarrollador**: Control total sobre las versiones de PHP, MySQL y otros servicios sin conflictos.
