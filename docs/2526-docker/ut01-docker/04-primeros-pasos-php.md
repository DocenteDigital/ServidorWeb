## ¿Qué veremos aquí?

- **Prerrequisitos**: Docker instalado y funcionando.
- **Comando `docker run`**: Anatomía del comando, mapeo de puertos y modo interactivo vs. background.
- **Gestión Básica**: Cómo listar, detener y eliminar contenedores que ya no necesitamos.
- **Tutorial**: Ejecución de un archivo `index.php` simple usando la imagen oficial de PHP con Apache.
