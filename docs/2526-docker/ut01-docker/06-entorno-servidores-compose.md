Docker Compose es la herramienta que nos permite definir entornos multi-contenedor en un solo fichero YAML.

## ¿Qué veremos aquí?

- **Introducción a `docker-compose.yml`**: Sintaxis, servicios, redes y volúmenes.
- **Arquitectura del Proyecto**: Diagrama de comunicación entre servicios.
- **Tutorial Paso a Paso**: 
    1. Creación del fichero de configuración.
    2. Levantar todo el stack con un solo comando.
    3. Acceso a phpMyAdmin para gestionar la base de datos MySQL.
    4. Conexión de PHP con la base de datos.
