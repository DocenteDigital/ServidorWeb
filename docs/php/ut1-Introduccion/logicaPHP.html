¿Qué es un algoritmo?

Un algoritmo es un conjunto finito de instrucciones ordenadas y no ambiguas que permiten resolver un problema determinado. Es decir, un algoritmo es como una receta de cocina, que nos dice paso a paso cómo preparar un plato determinado.

Características de un algoritmo

Las características de un algoritmo son:

  • Debe ser finito: Debe tener un número finito de instrucciones.
  • Debe ser preciso: Las instrucciones deben ser claras y no ambiguas.
  • Debe tener un punto de inicio y un punto de fin: Debe tener un punto de inicio y un punto de fin.
  • Debe tener un resultado: Debe tener un resultado.

Lenguajes de programación

Un lenguaje de programación es un lenguaje que permite comunicarse con una computadora. Es decir, un lenguaje de programación es como un idioma, que nos permite comunicarnos con una computadora.

Tipos de lenguajes de programación

Los tipos de lenguajes de programación son:

  • Lenguajes de bajo nivel: Son lenguajes que están muy cerca del hardware de la computadora. Son difíciles de entender y de programar.
  • Lenguajes de alto nivel: Son lenguajes que están más alejados del hardware de la computadora. Son fáciles de entender y de programar.

Estructura de un programa

La estructura de un programa es la siguiente:

  • Entrada: Es la información que se le da al programa.
  • Proceso: Es la información que se procesa en el programa.
  • Salida: Es la información que se le da al programa.

Ejemplo de algoritmo

A continuación, se muestra un ejemplo de algoritmo:

Inicio
  Leer un número
  Si el número es par, imprimir "El número es par"
  Si el número es impar, imprimir "El número es impar"
Fin

El pseudocódigo es una forma de representar un algoritmo de manera que sea fácil de entender para los humanos. Es decir, el pseudocódigo es como un idioma, que nos permite comunicarnos con una computadora. Pero no es un lenguaje de programacion como tal ya que no se puede ejecutar. El pseudocódigo utiliza palabras clave y estructuras que son comunes a muchos lenguajes de programación, lo que facilita su traducción a un lenguaje de programación real. Las estructuras del pseudocódigo son las siguientes:

  • Inicio: Indica el inicio del algoritmo.
  • Fin: Indica el fin del algoritmo.
  • Leer: Indica que se debe leer un valor.
  • Escribir: Indica que se debe escribir un valor.
  • Si: Indica una condición.
  • Entonces: Indica lo que se debe hacer si la condición es verdadera.
  • Si no: Indica lo que se debe hacer si la condición es falsa.
  • Mientras: Indica un bucle.
  • Hacer: Indica lo que se debe hacer en el bucle.
