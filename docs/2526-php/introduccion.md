PHP nacio en 1995 creado por Rasmus Lerdorf como unas herramientas para el seguimiento de su página personal. Al principio PHP eran las siglas de "Personal Home Page" pero actualmente son las siglas de "PHP: Hypertext Preprocessor" .

Es un lenguaje de programación interpretado del lado del servidor. Es decir, el código PHP se ejecuta en el servidor y el resultado se envía al cliente en forma de HTML. 



Las características principales de PHP son: 

- Es de código abierto.
- Es multiplataforma.
- Es fácil de aprender.
- Es rápido.
- Es seguro.
- Es escalable.
